## Multi-Platform Architecture

```
[Project Root]
├── CLAUDE.md          ←── Claude Code auto-loads (conditional startup)
├── GEMINI.md          ←── Gemini CLI entry point
├── AGENTS.md          ←── Cross-tool standard (any AI tool)
│
├── .context/          ←── Session & task files (organized, not at root)
│   ├── PICKUP.md      ←── Session handoff (read first if exists)
│   ├── PROJECT-MEMORY.md  ←── Persistent memory across sessions
│   ├── ARCHAEOLOGY.md ←── Legacy code map (generated by /archaeo)
│   ├── CODEBASE.md    ←── Project structure map
│   └── {task-slug}.md ←── Active plan file(s)
│
├── .claude/
│   └── rules/         ←── Auto-loaded by file type (Claude Code native)
│       ├── sql.md     ←── when editing *.sql, *.prisma
│       ├── test.md    ←── when editing *.test.*, *.spec.*
│       ├── css.md     ←── when editing *.css, *.scss
│       ├── api.md     ←── when editing routes, controllers
│       └── legacy.md  ←── when editing legacy/ folders
│
└── .agent/
    ├── CLAUDE.md      ←── Claude entry (inside .agent/)
    ├── GEMINI.md      ←── Gemini entry (inside .agent/)
    ├── ARCHITECTURE.md ←── This file
    ├── rules/
    │   ├── CORE.md         ←── Master protocol (~80 lines, always loaded)
    │   ├── CORE-WORKFLOW.md ←── Phase details (complex tasks only)
    │   ├── CORE-SCRIPTS.md  ←── Verification scripts (pre-deploy only)
    │   └── GEMINI.md        ←── Gemini redirect to CORE.md
    ├── agents/         ←── 21 specialist personas
    ├── skills/         ←── 40 knowledge modules
    ├── workflows/      ←── 12 slash commands
    ├── scripts/        ←── Master validation scripts
    ├── templates/      ←── Reference templates for .context/ files
    │   ├── PICKUP.md          ←── Session handoff template
    │   ├── PROJECT-MEMORY.md  ←── Persistent memory template
    │   ├── PLAN-TEMPLATE.md   ←── Task plan template
    │   ├── SPEC-TEMPLATE.md   ←── SDD spec template
    │   └── ARCHAEOLOGY-TEMPLATE.md ←── Legacy map template
    └── .shared/
        └── ui-ux-pro-max/ ←── Design data
```

## Skill Loading Protocol

```
User Request
    ↓
Skill description match
    ↓
Load SKILL.md (index + Content Map)
    ↓
Read only sections relevant to the request
    ↓
Load scripts/ or references/ if needed
```

**Selective Reading Rule:** Never load an entire skill folder. Always use the Content Map in `SKILL.md`.

## Native Rules (.claude/rules/) — Claude Code Only

Auto-loaded by file type being edited — no classifier needed:

| Rule File | Triggers When Editing |
|---|---|
| `sql.md` | `*.sql`, `*.prisma`, `*migration*`, `*schema*` |
| `test.md` | `*.test.*`, `*.spec.*`, `*/__tests__/*` |
| `css.md` | `*.css`, `*.scss`, `*.module.css`, `tailwind.config.*` |
| `api.md` | `route.ts`, `controller.*`, `*.api.*`, `*router*` |
| `legacy.md` | files in `/legacy/`, `/old/`, `/v1/`, `/deprecated/` |
